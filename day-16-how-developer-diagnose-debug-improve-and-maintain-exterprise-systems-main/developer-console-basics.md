# Developer Console Basics

## Overview

Developer Console is an integrated Salesforce tool used for development, testing, and debugging.

---

## Features

### Execute Anonymous

Run Apex code without creating a class.

Example:

```apex
System.debug('Hello Salesforce');
```

---

### Debug Logs

View application execution details.

---

### Query Editor

Run SOQL queries.

Example:

```sql
SELECT Id, Name
FROM Account
LIMIT 10
```

---

### Code Editor

Create and edit Apex classes and triggers.

---

### Log Inspector

Analyze application logs and performance.

---

## Common Uses

- Debug Apex code
- Test logic quickly
- Run SOQL queries
- Analyze governor limits
- Monitor execution flow

---

## Advantages

- Built into Salesforce
- Easy debugging
- Log analysis tools
- Rapid testing

---

## Conclusion

Developer Console is a valuable tool for Salesforce developers when testing and troubleshooting applications.
