# Answers

## What is Apex Replay Debugger?

Apex Replay Debugger is a Salesforce debugging tool that allows developers to replay Apex execution logs and analyze code behavior.

---

## What is a Debug Log?

A Debug Log records execution details of Salesforce operations and Apex code.

---

## What is Developer Console?

Developer Console is a Salesforce tool used to write, test, and debug Apex code.

---

## What can Developer Console be used for?

- Execute Anonymous Apex
- View Debug Logs
- Query Data
- Analyze Performance
- Debug Applications

---
