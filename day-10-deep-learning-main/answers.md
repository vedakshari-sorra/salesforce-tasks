# Answers

## What is Lightning Web Components (LWC)?

Lightning Web Components is Salesforce's modern framework for building reusable and high-performance user interfaces.

---

## What are the main files in an LWC?

- HTML File
- JavaScript File
- Meta XML File
- CSS File (Optional)

---

## How can LWC access Salesforce data?

- Lightning Data Service
- Wire Service
- Apex Methods

---

## What is Visualforce?

Visualforce is a Salesforce framework used to build custom user interfaces with Apex integration.

---

## What is Aura?

Aura is a component-based framework that was used before Lightning Web Components.

---

## What is the @wire decorator?

The @wire decorator connects Salesforce data and Apex methods to Lightning Web Components.

---

## Why use Lightning Web Components?

- Better performance
- Modern JavaScript support
- Reusable components
- Faster development

---

## Difference Between Aura and LWC?

| Aura | LWC |
|------|-----|
| Older framework | Modern framework |
| Complex syntax | Simpler syntax |
| Less performance | Better performance |
| Event-based | Standard web components |
