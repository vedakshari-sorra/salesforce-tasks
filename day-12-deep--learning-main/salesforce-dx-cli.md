# Salesforce DX & Command-Line Interface

## Overview

Salesforce DX (Developer Experience) is a set of tools and practices that support modern Salesforce development.

---

## Key Features

- Source-driven development
- Version control integration
- Scratch orgs
- Continuous integration
- Team collaboration

---

## Salesforce CLI

Salesforce CLI is used to interact with Salesforce through terminal commands.

### Common Commands

Create a project:

```bash
sf project generate --name MyProject
```

Authorize an org:

```bash
sf org login web
```

Create a scratch org:

```bash
sf org create scratch
```

Deploy source:

```bash
sf project deploy start
```

Retrieve source:

```bash
sf project retrieve start
```
