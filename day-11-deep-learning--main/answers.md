# Answers

## 1. What is Apex Testing?

Apex Testing is the process of validating Apex code to ensure it behaves as expected. Salesforce requires test classes before deployment to production.

---

## 2. Why is Apex Testing Important?

- Ensures code quality
- Detects bugs early
- Validates business logic
- Required for deployment
- Improves maintainability

---

## 3. What is the minimum code coverage required in Salesforce?

Salesforce requires at least **75% code coverage** for deployment to production.

---

## 4. What is Asynchronous Apex?

Asynchronous Apex allows code execution in the background without requiring users to wait for processing to complete.

---

## 5. What are the types of Asynchronous Apex?

1. Future Methods
2. Queueable Apex
3. Batch Apex
4. Scheduled Apex

---

## 6. When should Batch Apex be used?

Batch Apex should be used when processing large numbers of records that exceed governor limits.

---

## 7. Why is Queueable Apex preferred over Future Methods?

Queueable Apex provides:
- Job chaining
- Complex object support
- Better monitoring
- More flexibility

---

## 8. What is Scheduled Apex?

Scheduled Apex allows Apex classes to run automatically at specified times using a CRON expression.
