# Answers

## What is Lightning Data Service?

Lightning Data Service (LDS) allows Lightning Web Components to interact with Salesforce records without writing Apex code.

---

## What is the @wire decorator?

The @wire decorator is used to connect a component to Salesforce data or Apex methods.

---

## How can data be retrieved in LWC?

- Lightning Data Service
- Apex Methods
- Wire Service

---

## How does a parent communicate with a child component?

A parent component communicates with a child using public properties and methods decorated with @api.

---

## How does a child communicate with a parent component?

A child communicates with a parent by firing custom events.

---

## What is Visualforce?

Visualforce is a Salesforce framework used to create custom user interfaces using markup tags.

---

## What is an Apex Controller?

An Apex Controller provides business logic and data handling for a Visualforce page.

---

## Why use Lightning Web Components?

- Better performance
- Modern JavaScript support
- Reusable components
- Improved user experience
